Stations

A station is what the dashboard, statistics and alerts count, e.g. machine "M1". It counts one or more sources: each source is a device with its own OK, NOK, total and job values, so a station can have two cameras, or OK from one device and NOK from another.

Each source is one device with its own values: pick OK, NOK or both (a missing one counts as 0). Without a total, total = OK + NOK. A source without a job counts under the job of the first source that has one, else the job name below. A station without any source is fed by manual entries on its station view.
The station goes into production when one of its sources makes the set number of OK pieces within the set time, and those pieces count. Its counters only change while it is in production; changes outside production are logged but not counted.
If no source's OK increases for this long, the station leaves production: grayed on the dashboard, no counting, no scrap alerts.
Ideal cycle times for the OEE are set per job on the Jobs tab. Excluded stations keep their own rows in Scrap statistics but stay out of the totals, the Excel export totals, chat command totals and the OEE meter; single readings or periods can be included again.
Web pages of the station's devices, e.g. a camera's WebHMI (http://192.168.0.10/) or a PLC's web server, shown on the station view in this order. Each viewer's browser opens the page straight from the device, so it must be able to reach that address. Some devices don't allow their page inside another page; the station view then says so and offers to open it in a new tab.
