Backups

Take a backup regularly and keep it somewhere other than this server, for example with the automatic FTP backup below. A backup holds all app data: cameras, readings, counters, users and notification settings.

Download backup

Import this backup?

Importing replaces all current data (devices, readings, counters, users, notification settings) with the data in the file. The current data is saved first as a backup on this server, listed below, so the import can be undone by importing that file. You will be signed out and sign in with an account from the backup.

Automatic backup to FTP

Each run uploads one file named cognex-backup-DATE-TIME.json.gz and deletes the oldest of those files in the folder beyond the number to keep. Other files in the folder are not touched. Restore one with Import backup above.

Use a different database

The app runs inside a container, so localhost means the app container itself. Use the IP or name of the machine running PostgreSQL.
A saved database is used after the app restarts. If it cannot be reached at startup, the app falls back to the default (DATABASE_URL) and shows a warning here.
